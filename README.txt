Diksha Birthday Website - folder ka dhancha

index.html            -> yahi kholni hai (double-click)
css/style.css         -> sab design aur animation
js/script.js          -> 3D, mouse, music, kahani (Hindi story yahin 'pages' mein hai)
js/photos-data.js     -> 3D tairti photo frames ke liye photos ki copy
photos/1.jpg ... 6.jpg-> kitab wali photos
music/happy-birthday.wav -> built-in dhun
music/song.mp3        -> apna gaana yahan rakhein (is naam se), wo pehle chalega

Internet chahiye (3D library aur fonts ke liye). Page ke upar 'Your song' button se bhi gaana chun sakte hain.
Note: photos badalne par kitab ki photo turant badal jaati hai, par peeche tairte 3D frames purani photos hi dikhate hain jab tak js/photos-data.js na badle.
